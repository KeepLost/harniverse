# Agent Note: 斜杠命令图片附件信封

Status: implemented

[English](2026-08-25-slash-command-image-envelope.md) | 中文

## 问题

Web composer 可以随普通提示词提交持久图片，但斜杠命令 claim 只携带文本。Enter adjudication（判定）无法区分带图片的草稿，命令 Remote 没有图片信封，命令处理器也收不到持久附件引用。因此，携带图片提交 `/plan` 时会进入命令路径，却静默丢失图片。

只在浏览器声明检查无法保护直接 Remote、CLI、fixture 或同进程调用方。在解析命令及其能力前接纳字节，还可能为未知或不兼容图片的命令创建持久对象。若在分发开始时就释放浏览器文件，序列化、传输、取消、准入与处理器失败都会破坏输入，而无法重试。

## 决策

输入触发约定把 `SubmitEnvelope` 图片数量带入 Enter adjudication。拥有输入的 `CommandClaim` 声明 `images: true`；只有解析后的 Host 命令描述符声明 `input.images: true` 时，它才会收到有序 `SubmitImageAttachment` 载荷。未知命令、客户端 popup contribution、decoration、裸 Host 命令和未声明能力的输入命令都会在任何 UI 动作或 Remote 分发前拒绝携带图片的 Enter。

会话输入壳把 [composer 事务 owner](../bug-fix/2026-08-24-composer-transaction-and-cache-precision.md)扩展到命令图片序列化与 Host 结算。它只捕获未预留的图片 id，在每种非成功结算下保留草稿与浏览器资源，并且只在成功后移除 id 和撤销相应资源。取消与 scope dispose 会抑制迟到发布，并等待被保留的完成状态。

`CommandRuntime.execute(agent, line, images, signal)` 是权威能力边界。它先解析语法和生效命令，再开始附件工作；对直接与 Remote 调用方强制执行 `input.images`；通过 `admitEncodedImages` 解码规范 base64；并通过有序批量准入应用已挂载附件存储的部署限制。处理器收到冻结且与提供方无关的 `ImageBlock`，其中包含持久引用；命令包不导入任何提供方 wire 词汇。声明拒绝和准入拒绝都不会进入处理器，也不会创建持久图片对象。

准入后，每项语法和模型用途决定都归处理器所有。若某个子命令无法使用图片，它会返回错误，使 composer 保留源草稿。若图片进入模型可见输入，处理器会通过自身的普通持久领域消息路径写入；提供方适配器继续拥有请求投影。`/plan` 声明图片能力，拒绝图片与精确 `off` 子命令并用，并把有序持久图片块及其后的可选文本作为一条已记录用户消息 steer。

## 考虑过的替代方案

**在命令约定中复用提供方原生图片载荷。** 不予采纳，因为命令注册表与提供方无关。持久 `ImageBlock` 引用保留现有附件 seam，并让请求编码、上传与隐私策略继续归各提供方适配器所有。

**只在 Web 客户端强制执行图片支持。** 不予采纳，因为直接 Remote、CLI、fixture 和同进程调用方可以绕过呈现层检查，调用不兼容的处理器，或写入没有 owner 的附件。

**在每个命令处理器内接纳图片。** 不予采纳，因为每个命令都会重复 base64 校验、部署限制、存储查找、顺序与错误结算。执行器是唯一在进入处理器前知道已解析声明的操作。

**在序列化或 Remote 分发后释放浏览器资源。** 不予采纳，因为这两个时间点都不能证明命令成功。把原始草稿对象保留到成功结算，使每个失败路径都能重试，而无须重建用户输入。

## 验证

附件测试覆盖规范 base64、无效载荷、媒体策略、数量与总量限制、有序准入，以及批次校验完成前不写入。命令运行时测试覆盖未知与不支持的命令、直接调用强制执行、存储缺席、已接受的有序块、处理器抑制和附件准入错误。

客户端测试覆盖信封转发、popup 与裸命令拒绝、fixture Remote 转发、成功释放，以及序列化、传输、取消与处理器失败期间的草稿／图片保留。Plan 测试覆盖纯图片和图片／文本混合消息，以及 `/plan off` 拒绝。一个无密钥的组装 Web 组合覆盖不支持时保留输入和纯图片 `/plan` 成功清理。

## 后果

命令声明只增加一个小型图片能力，命令处理器则收到与普通模型输入相同的持久且与提供方无关的块载体。直接调用方无法绕过策略，已接受的 `/plan` 图片会成为可从日志重建的输入，同时不改变普通提示词投影。

成功的命令图片提交会在进入处理器前完成浏览器编码与 Host 持久准入。持久准入后的取消可能留下一个无引用不可变对象，交由附件 seam 的延迟垃圾回收策略处理；由于命令没有成功结算，浏览器源仍保持可用。
