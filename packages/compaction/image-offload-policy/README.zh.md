# @deepseek-ai/dsh-image-offload-policy

[English](README.md) | 中文

基于图片年龄的卸载契约。它拥有全局 `imageOffloadAfterUserTurns` 设置的形状（默认 `'unlimited'`，或正整数）、在一个请求组装点选择卸载哪些图片出现的纯决策规则、这些决策追加成的持久 `image/offload` 会话事件，以及模型在卸载图片位置看到的规范桩文本。

每张图按其出现位置之后的 `user/message` 事件计数——assistant 消息、工具流量和上下文快照从不计数。设为 4 时，图片在第四个后续用户轮次组装时卸载，除非提供方压力或压缩已经处理过它；已被更早的 `image/offload` 记录、或其载体事件已被压缩替换遮蔽的出现视为完结，不会再被选中。原始附件保留用于回放和授权重读；本包不删除任何附件字节。

本包只提供契约。应用这些决策的压缩与请求投影——包括桩渲染和提供方压力信号——由组合本包的图片卸载运行时交付。

## Model Experience

### 图片卸载决策

#### 模型看到什么

`image/offload` 决策追加后，后续请求在每张被卸载图片的位置渲染规范的 `OFFLOADED_IMAGE_STUB_TEXT` 桩文本。桩文本声明原始附件保留在当前请求之外、不得将图片视为可见。本插件自身不贡献任何提示词、工具或请求。

#### Token 效应

每张卸载的图片从后续请求中移除其图片 token。桩文本本身为每张卸载图片增加固定的一行成本。

#### KV Cache 效应

卸载改变了图片所在位置的请求内容，因此前缀复用在第一张被卸载图片处结束。这是卸载的后果，不是策略可以施加的延迟：达到配置的用户轮次年龄总是立即卸载，缓存复用从不推迟它。

## Known Limitations and Deferred Work

- 本包只做决策、不做投影：把决策应用到模型请求、接入提供方压力信号、以及设置 UI，属于组合本契约的图片卸载运行时。
- 不带 `sourceEventSeqs` 的压缩替换不引用任何事件，因此不会完结任何出现；投影将它们的覆盖范围视为不可归属。
