# @deepseek-ai/dsh-plugin-diagnostics

[English](README.md) | 中文

用于结构化插件诊断的只读注册表。服务注册 `ctx.pluginDiagnostics`；产品包通过 effect 作用域注册贡献稳定的检查 id、说明和 `diagnose()` 回调。`ctx.pluginDiagnostics.diagnose()` 对当前注册项制作快照，依次运行检查，隔离每项失败，并返回按严重程度排序的 `PluginDiagnosticReport`。

发现项包含所属检查、稳定代码、严重程度、运行时域、消息、可选诊断路径和可选文本处理建议。贡献不能冒用其他检查 id 发布发现项。服务不公开修复回调、重启操作、配置写入、进程控制或持久事故状态。

可安全传输为 JSON 的报告类型通过 `./types` 发布。消费者可以通过另行授权的 wire 操作公开报告，而无需导入服务实现。

## 模型体验

无。插件诊断只观察运行时状态，不注册提示词、工具、消息或提供方请求。

#### KV Cache 影响

无；诊断不组装模型输入。

## 已知限制与暂缓事项

- **时间点报告** — 注册表保留检查，不保留发现项或事故历史；需要时间序列的调用方必须在此服务之外持久化或比较报告。
- **顺序检查** — 缓慢贡献会使后续检查等待其取消或结束；首版目前仅运行本地有界检查，因此不拥有超时策略。
