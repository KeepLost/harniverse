# @deepseek-ai/dsh-client-ui-secret-mask

[English](README.md) | 中文

已发送 Web 用户文本的凭证显示掩码。用户消息里粘贴了可识别的凭证——提供方 API key、代码托管或包仓库令牌、云访问 key ID、JSON Web Token、私钥块,或携带凭证的地址密码——该值以掩码绘制:带前缀的 key 保留前八个字符,其余每个字符画成掩码记号。掩码只改变绘制出来的样子;消息文本、复制动作与模型输入都保持原始字符。

这是一个纯客户端插件:向会话服务的已发送用户文本面(`ctx.conversation.sentUserText`)注册一条规则,外加自己的词典。随发 Web 组合挂载;移除该行则凭证按原样绘制。

## 使用本包

把插件挂在 `dsh-client-ui-conversation` 旁边。会话聊天视图绘制的每个用户气泡都会咨询该缝:纯文本段保留既有的引用 chip 装饰,命中的区间经由规则的 `SecretText` 组件渲染。已发送消息与已准入的介入消息是可交互的:每个掩码值末尾有一个眼睛控件,可单独显示或隐藏该值,且每次挂载都从掩码状态开始。准入前的待定回显只绘制掩码值,不提供控件。

## 掩盖哪些值

| 值 | 示例 | 显示 |
| --- | --- | --- |
| 模型服务与 Google API key | `sk-…`(前 256 字符含数字)、`AIza…` | 保留前八字符 |
| 代码托管与包仓库令牌 | `ghp_…`、`github_pat_…`、`glpat-…`、`npm_…`、`hf_…` | 保留前八字符 |
| 云访问 key ID | `AKIA…`、`ASIA…`、`LTAI…`、`AKID…` | 保留前八字符 |
| 协作与支付令牌 | `xox[a/b/p/r/s]-…`、`sk_live_…`、`rk_test_…`、`whsec_…` | 保留前八字符 |
| JSON Web Token | `eyJ…` 三段点分 | 保留前八字符 |
| 私钥块 | `-----BEGIN … PRIVATE KEY-----` | 保留 `BEGIN`/`END` 行,正文掩码 |
| 地址密码 | `scheme://user:password@…` | 密码掩码;用户名、主机与路径保持可读 |

识别只依据已发布的格式本身。自由格式的密码、`name=value` 赋值与普通单词永远不会命中;识别器也不读取配置或已存凭证——它无法知道哪些密钥是真的,所以按形状绘制。

## 实现

匹配器是前缀剪枝的线性扫描器(`CredentialScanner`):纯字面量交替找到每种格式可能开始的位置,格式校验是有界的字符类奔跑、不可能回溯,奔跑终点与私钥块终点按文本跨查询记忆。识别在返回区间之前不发生任何分配。`benchmarks/user-text.bench.ts` 门守住单文档成本预算,回溯式回归无法悄悄落地。

## 模型体验

无,因为掩码只存在于 Web 客户端的显示层:不改变任何持久事件、工具 schema 或模型请求。

#### KV 缓存影响

掩码从不离开浏览器;不存在可失效的请求前缀。

## 已知限制与未竟工作

- **只掩码已发送的用户文本** —— 助手输出、工具结果与输入框草稿按原样渲染。输入框预览是自然的后续面。
- **识别只看格式** —— 未公开或自定义的格式保持明文;没有可供比对的已配置密钥清单。
- **显示状态属于单个挂载** —— 离开再回来会重新掩码;该状态刻意不持久化。
