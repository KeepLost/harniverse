# @deepseek-ai/dsh-client-ui-message-quotes

[English](README.md) | 中文

已发送 Web 用户文本的引用块呈现。用户消息里连续多行各自携带显式 Markdown 引用标记——至多三个前导空格后的 `>`——该区间绘制为一段引用摘录:次级颜色的左侧竖线块,并去掉一层标记。更深的标记与内部 Markdown 保持字面;摘录不会被再次解释。引用只改变绘制出来的样子;消息文本、复制动作与模型输入都保持原始字符。

这是一个纯客户端插件:向会话服务的已发送用户文本面(`ctx.conversation.sentUserText`)注册一条规则。随发 Web 组合挂载;移除该行则引用行按原样绘制。

## 使用本包

把插件挂在 `dsh-client-ui-conversation` 旁边。会话聊天视图绘制的每个用户气泡都会咨询该缝:纯文本段保留既有的引用 chip 装饰,命中的区间经由规则的 `QuotedUserText` 组件渲染。该呈现没有交互;可交互行与准入前的待定回显绘制同样的摘录。

## 识别哪些输入

| 输入 | 示例 | 显示 |
| --- | --- | --- |
| 连续显式引用行 | `> first\n> line` | 一段摘录,去掉一层 `>` |
| 缩进标记 | `␣␣> text`(至多三个空格) | 同一段摘录;去掉标记及其后一个空格或制表符 |
| 更深引用层级 | `> > nested` | `> nested`,按字面绘制 |
| 行内大于号 | `a > b` | 普通文本 |
| 缩进代码 | `>` 前有四个及以上前导空格 | 普通文本 |
| 空摘录 | 仅 `> ` | 普通文本(不绘制任何内容) |

一个区间在第一行没有自身标记处结束;摘录必须非空白,所以仅标记或仅空白的区间保持原样。

## 实现

识别器是官方 `dsh-session-message-quotes` 插件识别部分的近乎逐字移植:`quoteTextOf` 去掉每行一层标记并规范化行尾;`messageQuoteRanges` 以原始 UTF-16 偏移扫描显式标记区间。规则按单一文本记忆区间,该缝的递进偏移查询不会重扫。官方的选区按钮及其词典不在范围内,未予移植。

## 模型体验

无,因为引用只存在于 Web 客户端的显示层:不改变任何持久事件、工具 schema 或模型请求。

#### KV 缓存影响

引用从不离开浏览器;不存在可失效的请求前缀。

## 已知限制与未竟工作

- **只呈现已发送的用户文本** —— 助手输出、工具结果与输入框草稿按原样渲染。
- **不识别惰性续行** —— 引用段后不带标记的续行绘制在摘录之外,遵循仅显式标记的契约。
- **只去掉一层标记** —— 更深层级在摘录内按字面绘制,不做视觉嵌套。
