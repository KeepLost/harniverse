# `@deepseek-ai/dsh-client-ui-peer-admin`

[English](README.md) | 中文

配对 Harniverse 同伴的 Web 治理面。它提供仪表盘的「配对同伴」标签页,消费生成式 `peer` Remote 契约中 owner 的 administer 能力动词,并由转发的 `peer/paired`、`peer/removed` 宿主事件实时刷新。

标签页列出每个已配对同伴的身份、最近活跃时间、已授予的能力面、待审批的能力面请求、月度回合预算与委派会话数。Owner 可以直接编辑已授予的能力面(三个授权开关;owner 自己的决定无需审批),批准或拒绝由同伴发起并挂起为 pending surface 的扩张请求,设置或解除每同伴的月度已投递回合上限,以仅元数据行(实时状态、最近活跃、创建标签 —— 全文留在常规会话视图)审计同伴的委派会话,并通过显式确认步移除同伴。移除会结束该同伴的委派会话并丢弃其治理条目;配对侧在下一次调用解析不到记录时得知移除已发生。

闭环的 peer 错误原因 —— `RECORD_NOT_FOUND`、`INVALID_PAYLOAD`、`STORE_FAILED`、`CORRUPT_INSTANCE` —— 以本地化文案呈现而非原始报错;预算输入在客户端按宿主强制的同一个 1..1000000 整数界校验。

## Model Experience

无。该浏览器侧管理面只暴露经过认证的 operator 动作,不注册任何模型上下文、工具、事件或请求字段。

#### KV Cache effect

无直接影响。该标签页不改变模型请求前缀。

## Known Limitations and Deferred Work

- 审计行按设计仅含元数据:读取委派会话的全文仍走常规会话视图,任何全文文本都不经过管理 Remote。
- 预算用量按已被接受的投递回合计数;被限额同伴的在途回合仍可能超出上限,超出量以并发投递数为上界,宿主侧将此记录为至多在途数的越界。
- 同伴的待审批能力面请求没有过期时间:单个待审槽位被每个更新的扩张请求覆盖,并在批准、拒绝、owner 编辑或同伴侧收窄提交时清除。
