# `@deepseek-ai/dsh-client-ui-remote-hosts`

[English](README.md) | 中文

SSH 管理的远程 Harniverse 主机 Web 管理界面。它在现有设置、定时任务和会话管理界面旁边增加侧栏入口与中心视图，并在 `sidebar.workspaces.machine` slot 中提供侧栏机器指示器。主机选择与连接操作由此页面负责；页面当前的连接目标始终是活跃的工作区机器，直到某一行或指示器将其切换。

页面使用生成的 `remoteHosts` Remote 契约，列出不含秘密的主机记录，在保存前检测连通性，通过 Host 凭据提供方保存密码或私钥，连接和断开不会停止远程进程，并配置明确的远端来源到本地目标的反向映射。提交后不会再次渲染私钥值或口令。已连接的主机行会通过连接目标 seam 在同一文档内把整个页面切换到该机器，同时关闭本视图；侧栏机器指示器随后显示活跃机器的名称（解析其配置的显示名）并提供无条件返回本机的操作，而主机管理始终保留在原始页面权威上。

中心视图沿用定时任务页面的骨架（固定头部，含已连接计数摘要与操作区，其下为滚动的卡片列表；添加主机的编辑器是右侧抽屉，按 Escape 关闭）。密钥登录默认走宿主本地路径，由 `remoteHosts.keyFilePicker()` 路由：`native` 组合由 Host 打开以操作者 `~/.ssh` 为起始目录的原生单文件选择器（`remoteHosts.pickKeyFile()`）；`browse` 组合打开应用内密钥文件浏览器（`remoteHosts.listKeyFiles()`），逐层列出 Host 所在机器——绝不是浏览器所在机器——的目录，目录进入下一层、文件直接选中，因此选定的凭据始终是具体文件；探针失败则保留手动输入路径。保存的凭据就是路径本身，由 Host 在使用时读取文件，同样受 64 KiB 上限约束。一个共享的密码输入框承载登录密码或私钥口令，随所选登录方式切换。勾选「手动粘贴密钥内容」后互斥切换——粘贴可用、路径输入与拾取按钮禁用——取消勾选则相反。平台与架构默认「连接时决定」：编辑器把它们收在默认折叠的可选设置区里，保存时若操作者未显式固定，则以连通性检测探测到的值为准。封闭的 `KEY_*` 线上错误码——以及连接时的 `ARTIFACT_NOT_FOUND` / `INVALID_ARTIFACT` / `CREDENTIAL_REQUIRED` reason——会以本地化文案呈现，而不是原始消息。

连接反馈是即时的：被点击的行从第一次点击起就显示连接中状态，先于任何协调器状态到达，并且在有连接进行中或任一主机处于连接／部署状态时，列表持续轮询。部署中的行会呈现协调器有界的 `progress` 字段：当前阶段——检查远程服务端产物、上传产物（唯一携带计数的阶段，按文件计数）、校验、准备远端授权、启动远程服务端、建立 SSH 隧道、同步设置与凭据——并附带无障碍标签。切换失败或被拒绝时，错误显示在本视图内；切换机器绝不会导航离开。

## 模型体验

本包不贡献模型可见提示词、工具、事件或请求字段。主机操作始终是经过认证的 Remote 操作。

#### KV Cache 影响

没有直接影响。中心视图不会改变模型请求前缀。

## 已知限制与延期事项

- 表单创建主机记录并管理其生命周期；修改已保存记录需要删除并重新创建，从而避免已连接会话静默改变指纹或凭据引用。
- 保存前必须通过一次连通性检测；任何对被检测地址、端口、用户或凭据的修改都会使其失效，因此表单保存的始终是登录已被证实的指纹，而不是操作者手输的值。此后主机密钥一旦变化，会表现为检测失败，而不会被静默接受。
- 反向映射在连接前配置，连接完成后才启用；请求路由和重连状态由传输协调器负责。
- 远程机器目标要求本地协调器保持主机连接；离开页面不会停止远程进程，而断开协调器后远程目标会等待本地主机重新连接。
