# `@deepseek-ai/dsh-client-ui-remote-hosts`

[English](README.md) | 中文

SSH 管理的远程 Harniverse 主机 Web 管理界面。它在现有设置、定时任务和会话管理界面旁边增加侧栏入口与中心视图；当前机器仍是工作区上下文，主机选择与连接操作由此页面负责。

页面使用生成的 `remoteHosts` Remote 契约，列出不含秘密的主机记录，在保存前探测并展示待独立确认的 SSH 指纹，通过 Host 凭据提供方保存密码或私钥，连接和断开不会停止远程进程，并配置明确的远端来源到本地目标的反向映射。提交后不会再次渲染私钥值或口令。已连接的主机行会以 `dshRemoteHost` 打开新的页面；原始本地页面继续作为管理权威。

## 模型体验

本包不贡献模型可见提示词、工具、事件或请求字段。主机操作始终是经过认证的 Remote 操作。

#### KV Cache 影响

没有直接影响。中心视图不会改变模型请求前缀。

## 已知限制与延期事项

- 表单创建主机记录并管理其生命周期；修改已保存记录需要删除并重新创建，从而避免已连接会话静默改变指纹或凭据引用。
- 反向映射在连接前配置，连接完成后才启用；请求路由和重连状态由传输协调器负责。
- 远程页面要求本地协调器保持主机连接；关闭页面不会停止远程进程，而断开协调器后远程页面会等待本地主机重新连接。
